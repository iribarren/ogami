# Glossary

Each term below keeps the meaning given here all through the book.

## Games and flows

| Term            | Meaning                                                                                                                                                                                                     |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GameSystem      | The rules of a game, made up of its dice and Checks, its character sheet and gear, and its oracles. One GameSystem can hold many flows                                                                      |
| NarrativeFlow   | A guided way of playing inside a GameSystem, set out as ordered Phases of scenes that run from the story's first question to its last                                                                       |
| Phase           | One of the ordered parts of a flow. It runs once or loops, and it has its own rule for choosing the next scene                                                                                              |
| Act             | An optional label for a group of Phases, which does not make the group a level of the flow                                                                                                                  |
| Session Zero    | By convention the first Phase of a flow, where you make the characters and the world                                                                                                                        |
| Scene Type      | A kind of scene you can use again, with a purpose, tips, steps for its setup, play and closing, and the oracles it suggests                                                                                 |
| Scene selection | The way a Phase picks its next Scene Type: `sequence` (in order), `player` (you choose) or `oracle` (a roll or a draw)                                                                                      |
| Step            | One instruction inside a scene. Most steps are a prompt, a choice, an oracle, a table, a roll, a Check, a condition or a pick, while the two other kinds, Character and Shop, build a character and its kit |
| Hook            | The steps a Phase runs at a boundary, such as the start of a session, a Phase or a scene, or between scenes as the World turn                                                                               |
| World turn      | A Hook that runs between scenes and lets the world move, as when a clock advances, a table is rolled or someone goes missing                                                                                |
| Effect          | A change that a step or an oracle table entry applies, such as moving a Tracker, forcing the next scene, ending the Phase or filling a Fact slot                                                            |

## Memory and pressure

| Term      | Meaning                                                                                                                      |
| --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Fact      | Something you have written down as true about the story                                                                      |
| Fact slot | A named place, such as "The Sin", for a Fact the flow will ask you for                                                       |
| Truth     | The answer the story is written towards: sealed, emergent or fixed                                                           |
| Thread    | An open question, asked by a line of the story or raised when someone gives their word, which stays open until you answer it |
| NPC       | A person in the story who is not one of the characters you play                                                              |
| Place     | A location you may return to, marked open or closed                                                                          |
| Tag       | A short label such as `crew`, put on an NPC, a character, a Place or a Thread so that a step can use it to pick from a list  |
| Tracker   | A number the flow keeps: a clock or a counter                                                                                |
| Clock     | A Tracker with a fixed number of boxes. Once every box is filled, something happens                                          |
| Counter   | A Tracker that rises and falls within a range                                                                                |

## Dice and rules

| Term              | Meaning                                                                                        |
| ----------------- | ---------------------------------------------------------------------------------------------- |
| Oracle            | Anything you put a question to and let chance answer, whether a table, a card or a die         |
| Likelihood oracle | An oracle that answers yes or no, weighted by how likely the answer is                         |
| Oracle table      | A list of results chosen by a roll, a draw or both, in which the common results get more rolls |
| Check             | A named roll that turns dice into a meaning                                                    |
| Outcome band      | A range of results with a meaning of its own, such as "Goes wrong", "Falls short" or "Done"    |
| Difficulty        | A target that a player sets before a roll                                                      |
| Trait             | A number on a character's sheet that a roll is compared against                                |
| Gear              | Equipment that a character carries, with a cost and a number of slots                          |
| Load              | How many slots of Gear a character can carry                                                   |
| Currency          | The number on the sheet that buys Gear                                                         |
| Credits           | The notice, license and link that say who made a GameSystem and on what terms                  |

## In Ogami

These terms only matter inside the app.

| Term         | Meaning                                                                                   |
| ------------ | ----------------------------------------------------------------------------------------- |
| Play         | Where you run a campaign                                                                  |
| Studio       | Where a GameSystem and its flows are authored                                             |
| Campaign     | One game being played, bound to a GameSystem                                              |
| FlowRun      | The progress of a campaign through its flow                                               |
| Draft        | The version of a GameSystem you are editing. Players never see it                         |
| Release      | A published, numbered, unchangeable version of a GameSystem. A campaign plays one release |
| Pinned       | A campaign stays on the release it started with until its player upgrades it              |
| Restore      | Replaces a draft with the content of an older release                                     |
| Library pack | A set of reusable items that GameSystems copy into their drafts                           |
| Theme        | One of five looks a release may choose for its campaigns                                  |
| Validation   | The check that says whether a draft could be published                                    |

:::
