# Glossary

The terms of this book, in the meaning each has throughout. Where a chapter uses a term, it uses it this way.

## Games and flows

| Term            | Meaning                                                                                                            |
| --------------- | ------------------------------------------------------------------------------------------------------------------ |
| GameSystem      | The rules of a game: its dice, its Checks, its character sheet and gear. One GameSystem can hold many flows        |
| NarrativeFlow   | A guided procedure of play inside a GameSystem: ordered Phases of scenes, from the first question to the last      |
| Phase           | An ordered part of a flow that runs once or loops, with a rule for choosing the next scene                         |
| Act             | An optional label that groups Phases. It is not a level of the flow                                                |
| Session Zero    | By convention a flow's first Phase: making characters and the world                                                |
| Scene Type      | A reusable kind of scene, with a purpose, tips and its setup, play and closing steps                               |
| Scene selection | How a Phase picks the next Scene Type: `sequence` (in order), `player` (you choose) or `oracle` (a roll or a draw) |
| Step            | One instruction inside a scene: a prompt, a roll, a table, a choice, a pick, a condition or a Check                |
| Hook            | Steps a Phase runs at a boundary, such as the start of a session or the World turn                                 |
| World turn      | A step between scenes where the world moves: a clock advances, a table is rolled, someone goes missing             |
| Effect          | A change a step applies: move a Tracker, force the next scene, end the Phase, fill a Fact slot                     |

## Memory and pressure

| Term      | Meaning                                                                                |
| --------- | -------------------------------------------------------------------------------------- |
| Fact      | A thing you have written down as true about the story                                  |
| Fact slot | A named place for a Fact the flow will ask for, such as "The Sin"                      |
| Truth     | The answer the story is written toward. Sealed, emergent or fixed                      |
| Thread    | An open question or promise, open until you answer it                                  |
| NPC       | A person in the story who is not one of the characters you play                        |
| Place     | A location you may return to, open or closed                                           |
| Tag       | A short label on an NPC, a Place or a Thread, such as `crew`, used to pick from a list |
| Tracker   | A number the flow keeps, either a clock or a counter                                   |
| Clock     | A Tracker with a fixed number of boxes. When full, something happens                   |
| Counter   | A Tracker that rises and falls within a range                                          |

## Dice and rules

| Term              | Meaning                                                                           |
| ----------------- | --------------------------------------------------------------------------------- |
| Oracle            | Anything you ask a question of by chance: a table, a card or a die                |
| Likelihood oracle | An oracle that answers yes or no, weighted by how likely the answer is            |
| Oracle table      | A list of results chosen by a roll, a draw or both. Common results get more rolls |
| Check             | A named roll that turns dice into a meaning                                       |
| Outcome band      | A range of results with a meaning, such as "goes wrong", "falls short" or "done"  |
| Difficulty        | A target a player sets before a roll                                              |
| Trait             | A number on a character's sheet that a roll is compared against                   |
| Gear              | Equipment a character carries, with a cost and a number of slots                  |
| Load              | How many slots of Gear a character can carry                                      |
| Currency          | The number on the sheet that buys Gear                                            |
| Credits           | The notice, license and link that say who made a GameSystem and on what terms     |

## In Ogami

These terms only matter inside the app.

| Term         | Meaning                                                                                   |
| ------------ | ----------------------------------------------------------------------------------------- |
| Play         | Where you run a campaign                                                                  |
| Studio       | Where a GameSystem and its flows are authored                                             |
| Campaign     | One game being played, bound to a GameSystem                                              |
| FlowRun      | The progress of a campaign through its flow                                               |
| Draft        | The version of a GameSystem you are editing. Players never see it                         |
| Release      | A published, numbered, unchangeable version of a GameSystem. A campaign plays one release |
| Pinned       | A campaign stays on the release it started with until its player upgrades it              |
| Restore      | Replaces a draft with the content of an older release                                     |
| Library pack | A set of reusable items that GameSystems copy into their drafts                           |
| Theme        | One of five looks a release may choose for its campaigns                                  |
| Validation   | The check that says whether a draft could be published                                    |

:::
